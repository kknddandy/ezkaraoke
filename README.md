# ezkaraoke

家用 KTV 点歌系统 — 简单易用的家庭卡拉 OK 解决方案。

## 功能特性

- **本地曲库管理**：自动扫描指定文件夹，构建歌手-歌曲索引
- **经典点歌台界面**：左侧歌手列表 / 中间歌曲浏览 / 右侧播放队列
- **多种点歌方式**：支持按歌手浏览、实时搜索、点歌/插播/立即播放
- **播放队列管理**：支持队列内上移、下移、删除，双击切歌
- **原唱/伴奏切换**：双音轨视频歌曲一键切换原唱与伴奏，播放窗口与点歌台同步，偏好跨歌曲保留
- **双窗口模式**：独立的视频播放窗口 + 点歌台窗口
- **深色 KTV 主题**：沉浸式暗色界面，搭配暖色点缀

## 文件名约定

扫描器按以下格式识别歌曲文件：

```
歌手-歌曲名称-xxxxx.xxx
```

例如：`周杰伦-晴天-OfficialMV.mp4`

横杠 `-` 用于分隔歌手与歌名，后面的附加信息会被忽略。

## 环境要求

- Python 3.10 或更高版本
- PySide6 6.11.2+
- VLC 媒体播放器（用于视频解码）

### Ubuntu / Debian

```bash
sudo apt update
sudo apt install vlc
```

## 安装与运行

```bash
# 克隆仓库后进入目录
cd ezkaraoke

# 创建虚拟环境
python3 -m venv .venv
source .venv/bin/activate

# 安装依赖
pip install -r requirements.txt

# 启动程序
python run.py
```

## 使用说明

1. 在点歌台窗口点击 **"选择文件夹…"**，指定存放歌曲的文件夹
2. 程序自动扫描并建立曲库，左侧显示歌手列表
3. 浏览歌手或直接在搜索框输入关键词查找歌曲
4. 选中歌曲后点击：
   - **点歌**：将歌曲加入播放队列末尾
   - **插入播放**：将歌曲插到当前播放的下一首
   - **立即播放**：立即播放该歌曲
5. 在右侧播放队列中可调整顺序或删除歌曲，双击队列歌曲可切歌
6. 播放器窗口支持双击视频区域切换全屏，按 `Esc` 退出全屏，按 `Space` 暂停/播放
7. 带两条音轨的歌曲可通过播放器窗口或点歌台的 **"原唱/伴奏"** 按钮切换音轨（当前音轨显示在按钮提示中）

## 注意事项

- 视频输出策略按会话自动选择：
  - **X11 / XWayland**：使用窗口句柄硬件加速直出（`set_hwnd`）。
  - **原生 Wayland**：自动切换为软件渲染模式（VLC 解码后回读帧到 Qt 显示，CPU 占用略高，功能完整）。
- 若提示缺少 VLC，请确保系统已安装 VLC 并可通过命令行调用。
